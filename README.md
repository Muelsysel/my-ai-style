# my-ai-style

个人 AI 协作规范与素材库：操作规约、写作风格卡、可复用提示词模板。

目的是把已验证有效的约束沉淀成可直接复制的文件，不必在每次对话里重复交代。

## 目录

| 路径 | 内容 | 用法 |
| --- | --- | --- |
| `agents/AGENTS.md` | 协作规约：权限边界、执行原则、验证与交付、汇报习惯 | 复制到目标仓库根目录，按第 5 节填写项目索引 |
| `style/voice-card.md` | 个人写作风格卡：基调、语言特征、禁用表达、常用句式 | 产出文字内容的任务开始前附加给模型 |
| `prompts/ppt-technical-deck.md` | 技术项目汇报 PPT 提示词：事实原则、低对比度配色、版式规范 | 整段粘贴使用 |

## 使用原则

- 规约按字面范围执行，只覆盖当次需求，不顺手扩展。
- 风格卡是约束，不是润色指令；只在需要贴合个人文风时附加。
- 模板里的占位符（如 `[待补充实测数据]`）在使用时替换，不要保留在交付物中。

## 来源

整理自三份个人文档：`agents.md`、`写作风格.txt`、`常用提示词.txt`。原 `常用提示词.txt` 后半段与 `agents.md` 重复，已合并去重。
